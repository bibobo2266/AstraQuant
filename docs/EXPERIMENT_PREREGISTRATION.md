# Experiment Preregistration

Every serious experiment is frozen before results are inspected.

A preregistration should define:

- hypothesis and proposed mechanism
- universe and sample period
- target/label
- baseline and candidate
- exact feature versions
- primary and secondary metrics
- walk-forward protocol
- execution assumptions
- multiple-testing plan
- falsification plan
- promotion criteria
- stop conditions
- locked future OOS definition, if used
- parameters fixed before the run

## Change rule

A frozen preregistration is never edited to match observed results.

If the protocol changes after seeing evidence, create a new experiment ID such as EXP-R001B or EXP-R001C. Every attempted variant still counts toward the research trial history.
