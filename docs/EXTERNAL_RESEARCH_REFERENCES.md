# 外部研究參考 — 籌碼三關篩選法

## 這份文件的地位

**參考，不是證據。** 以下是第三方在不同條件下的實驗紀錄，供研究設計時參照，
**不得用來支持或推翻 AstraQuant 任何策略的結論**。

來源：`wirelessr/three-gate-screener`（README 與 docs/RESULTS.md），2026-09-30 讀取，
**commit SHA 未固定**。作者結論為「在其測試範圍內找不到可靠 edge」。

## 為什麼不能當證據 — 四項條件皆不同

| 項目 | 該專案 | AstraQuant |
|---|---|---|
| 期間 | 2023-01 ~ 2026-04（約 3 年） | E1 2016-01-04 ~ 2021-12-31（6 年） |
| 母體 | 476 檔（依 total_lots 取 top 500 後扣除視窗不全者） | all_liquid + P2-060 凍結排除，全市場 |
| 策略類型 | 籌碼面三關（法人連買 / 成本乖離 / 集保戶數） | 價量型態（VCP 收縮突破）等 |
| 資料 | FinMind 免費 tier；**原策略要求的券商分點資料無法取得，以外資+投信合計代理** | PIT 價量、CA 一致口徑、下市生命週期處理 |
| 出場 | walk-forward + 固定百分比停損 | ATR 移動停利 + 跌破 MA，收盤確認次日開盤成交 |

作者本人在 README 明確聲明：**「所謂『策略無 edge』的結論僅適用於我們的免費代理實作，
不能推論到原策略本身。」** 本文件遵守同一界線，並再加一層：也不能推論到 AstraQuant 的任何策略。

## 記錄下來的原因

不是因為它失敗。是因為它**把失敗的方式拆開來寫**，這在公開 repo 極少見，
對研究設計有參照價值。以下三項列為「值得在自家實驗中檢查的問題」，
**不是已成立的結論**。

### 一、他採用的淘汰規則

> 4 個年度全正 alpha 才算可靠的 edge。總計 0/15 組合通過。

這是比「全期期望值為正」嚴格的判準，用意在擋掉「靠某一年大多頭撐起全期」。
AstraQuant 的 E1 有六個年度，**可考慮增列逐年拆分作為診斷欄位**（非淘汰規則）。
是否採用同樣嚴格的門檻，屬 owner 決定，本文件不建議。

### 二、他掃停損後的觀察

六種停損（1.5% / 2.5% / 3% / 5% / 10% / 不停損）之下，其中兩個年度對所有停損值皆為負 alpha。
作者據此認為問題不在出場。

**這對 AstraQuant 的意義僅止於：出場軸掃描應同時保留逐年拆分，
以便區分「出場參數不對」與「該年進場訊號本身沒有預測力」。**
不能據此預判 VCP 的 D21 出場問題會不會因換出場而改變——那是不同策略、不同期間、不同資料。

### 三、不停損版本的數字型態

不停損在多頭三年為大正數、空頭季度立即轉大負，作者判讀為 beta 而非選股 edge。

**AstraQuant 已有自己的對應診斷**（移除前 1/3/5 筆最大獲利後的 expectancy、
高分組贏家重疊 Jaccard）。兩者是不同的檢查方式，各自獨立，不互為佐證。

## 可用的資料源線索

以下為該專案使用的公開資料源，與其結論無關，僅記錄可取得性：

- `wirelessr/tdcc-opendata-archive` — TDCC 集保股權分散表長期存檔，每日 GHA 自動更新，
  納入 lisa4930007 的 2021 Q3 歷史備份。TDCC 官方只保留最近一週，此存檔提供歷史。
- `https://opendata.tdcc.com.tw/getOD.ashx?id=1-5` — TDCC 官方 opendata（僅當週）
- `norway.twsthr.info` — 大戶持股比例衍生指標，該專案取得 2,369 檔 × 170 週（2023-01~2026-04）

**這些只是線索，尚未查證。** 採用前須各自確認：授權與使用條款、PIT 可用時間
（公布日而非資料所屬週）、歷史完整性與回溯修訂情形。
AstraQuant 目前 `INSTITUTIONAL_NET_BUY_STREAK` 與 `TRUST_VOLUME_RATIO_STREAK`
標為 BLOCKED_DATA，上述線索是否能解除該狀態，未經查證，不得預設可行。
