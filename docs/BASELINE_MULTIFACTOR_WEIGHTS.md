## 一、疊加權重配置

目前手上唯一一組完整的多面向權重：

```python
WEIGHTS = {"tech": 0.25, "fund": 0.25, "chips": 0.25, "whale": 0.15, "news": 0.10}
WHALE_W_NO_DELTA = 0.05     # 只有水位、無週變化時，大戶面向的降級權重
MIN_TURNOVER = 50_000_000   # 每日成交金額下限（元）
SHORTLIST = 60              # 第二階段深挖檔數
```

兩個結構性決定值得注意：

**市場氛圍不列入權重。** 作者註解：它是盤面級純量，不能拿來排序個股。
這與 AstraQuant 的分層一致 —— market_context 不做股票橫截面排名。
第三方獨立得出同樣結論，可作為該設計的旁證。

**大戶面向有降級機制。** 當只有持股水位、沒有週變化資料時，權重自 0.15 降到 0.05，
而非補中性值或整項剔除。這是「資料品質影響權重」的具體做法，
AstraQuant 目前的缺值政策是保持 null，兩者是不同取向，可並列比較。

**兩階段漏斗。** 第一階段全市場粗篩，取前 60 檔進第二階段深挖。
作者說明 60 這個數字的理由是：第一階段用月均價當技術面代理的誤差，
比前三名的分差還大，漏斗要留足夠緩衝。

## 二、產業中性化的判準

作者把「哪些因子該產業內排名、哪些不該」寫成明確判準，比一律中性化細緻：

**估值要產業內排**：金控 PB 0.8 與半導體 PB 4 是結構性差異，
同池比會讓金融股霸榜。

**獲利率刻意不產業內排**：25% 的營業利益率在哪個產業都是 25%，
與本益比性質不同。若也產業內排，等於讓低毛利產業在圈內互比後全體及格，
正好抵銷這一項存在的理由。作者將營益率定位為本益比失真的解藥 ——
本業毛利 7% 的公司靠認列子公司收益也能讓本益比看起來合理，用營益率排它自然掉下去。

**金融保險業整項給中性**：該業別的月營收含利息與投資收益，年增率不可比
（產業內中位 30%、最高 4392%，非金融只有 15%）。作者認為產業內排名擋不住這件事，
因為在金融股內部排出的名次本身沒有經濟意義，等於發一組隨機分數送進總分。

**業外佔比只當黃旗、不當排除**：台化的 65% 是持有台塑化的權益法收益（經常性），
端點無法拆出一次性處分利益，硬排除會誤殺控股公司。

以上四項是該作者的判斷，非公認標準。AstraQuant 若要做產業中性化，
可將其列為待測的替代方案之一，不預設採用。

## 三、資料處理註記

作者在註解中記錄的取捨，與策略無關，屬資料層。列此供 AstraQuant 自查參照，
**各項是否適用需自行確認，不得直接套用**：

**TWSE「月平均價」的定義**：是當月至今均價，不是 20 日均線。每月第一個交易日
它等於當天收盤。作者原本用它當技術面代理，發現那天市場寬度會算出 0%、
代理值變成常數，改用 FMSRFK 的上月加權均價。

**橫斷面分母須同一基準**：一部分用整月成交量、另一部分用當日量×20，
尺度不同會使名次錯誤而不只是差個常數。作者的處理是缺任何一檔就全體退回當日量。

**集保 CSV 截斷的方向性風險**：檔案依代號排序，截斷點落在某檔中間會讓該檔的級距
只加總一半，產生數十個百分點的假變化，並在大戶排名中居首。作者註記「缺很多反而安全」，
因為明顯的大量缺失會被發現，輕微截斷不會。

**買超天數與買超總額是兩件事**：外資鉅額轉倉、ETF 成分股調整、除權息前借券還券
都會產生單日巨額買超。作者採連續天數而非金額，判準為「5 天買 5 天才是建倉」。
這與 baseline 庫中麥克連（連買 2 日）、投信認養（連買 3 日）的設計方向一致。

**空字串與缺值的區別**：TWSE 以空字串表示不配息（全市場 1081 檔中 233 檔），
"0.00" 為 0 檔。若當缺值補中位數，等於讓 233 檔不配息的股票各拿半分。

**除權息與還原股價**：指標計算用還原價，畫面顯示用原始收盤。
台股 8-9 月除權息旺季，用原始收盤算均線與報酬率會把除息跳空當成下跌。
AstraQuant 已有 CA 一致口徑處理，此處僅記錄第三方同樣的處理方向。

**融資餘額的正規化**：融資限額由證交所依流通股數設定，
故「融資餘額 ÷ 融資限額」即為正規化後的散戶槓桿水位，不需另查發行股數。
券資比在融資餘額低於 1000 張時視為雜訊（179 張融資配 358 張融券會算出 200%）。

**普通股識別**：四碼數字且不以 0 開頭，可擋掉 00xxx ETF 與 5-6 碼權證；
存託憑證擋不掉（9103、9105 等亦為四碼），需另以名稱識別。
